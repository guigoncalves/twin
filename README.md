# Digital Twin

Gradio career twin. Deploy on Render as a Python web service:

- Build: `pip install -r requirements.txt`
- Start: `python app.py`

Set these environment variables (do not commit a `.env`):

- `OPENROUTER_API_KEY`
- `GRADIO_SERVER_NAME=0.0.0.0`
- `GRADIO_SERVER_PORT=10000`
- `PUSHOVER_USER` and `PUSHOVER_TOKEN` (optional)
